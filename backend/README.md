# OctoFit Tracker — Backend (Django REST)

This folder will contain the Django REST backend for OctoFit Tracker.

Setup (local):

1. Create & activate a Python virtual environment: `python3 -m venv .venv` & `source .venv/bin/activate`
2. Install dependencies: `pip install -r requirements.txt`
3. Start development server after adding a Django project/app.
